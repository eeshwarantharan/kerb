Kerb keeps your coding agent on the road: it refuses actions the environment forbids and retries that can't help, before they run, and shows you every save.

**Install:** `brew install eeshwarantharan/tap/kerb`, download a binary below (checksums in `SHA256SUMS`, build provenance attested), or `npm install -g kerb-cli`. Then run `kerb init` and `kerb doctor` in your repo.

**Demo:** see the recording in the README.

Every number in these notes comes from `kerb report` or the published benchmark in `bench/`.
